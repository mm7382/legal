## 常見問題

### 計算結果代表什麼意思？

時來－八字 依照傳統曆法規則，提供四柱與地支關係的說明。本版**不輸出吉凶、不排序最佳日、不推薦時辰**——那些判讀規則仍在研究校驗階段，未通過來源驗證前不會出現在 App 裡。這些說明**不構成任何保證或預測**。

### 我的資料會上傳到伺服器嗎？

不會主動上傳或同步至任何伺服器。所有出生資料與計算結果僅儲存於您的裝置本機。請注意：若您已啟用 iCloud 備份，裝置本機資料可能包含在 Apple 的 iCloud 備份中，此備份行為由您的 Apple ID 設定控制，非本應用程式主動操作。如不希望備份本應用程式資料，可在「設定 → Apple ID → iCloud → 管理 App 備份」中停用。詳情請見 [隱私權政策](privacy)。

### 如何刪除我的資料？

在應用程式中前往「管理與資料 → 清除出生資料、小工具與提醒」，即可刪除所有本機儲存的資料，包括命盤、通知與小工具快取。

### 免費版與會員版有什麼差別？

今天的完整內容免費，不需訂閱。會員版可多看未來七日、建立最多 5 個命盤，每個命盤追蹤最多 3 個事項。

### 如何取消訂閱？

請前往 iPhone「設定 → Apple ID → 訂閱」，找到「時來－八字」後取消。需在續訂日前至少 24 小時前完成取消，否則將自動扣款。取消後訂閱效益持續至目前週期結束。

### 如何恢復已購買的訂閱？

在應用程式中前往「管理與資料」，點選「恢復購買」，系統將驗證您的 Apple ID 訂閱記錄。

### 小工具沒有更新怎麼辦？

iOS 由系統決定小工具的更新時機，無法強制立即刷新。請先在應用程式中點「計算並更新小工具」，如問題持續，可嘗試移除並重新新增小工具。

### 出生時辰不知道怎麼辦？

在設定出生資料時，時辰輸入方式選「不知道」。系統會計算八字三柱（年、月、日），時柱欄位會標示「未提供」——不會用推測值填補。
